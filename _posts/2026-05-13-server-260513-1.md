(Rocky Linux 8 / Remi PHP 기준)

이 문서는 이미 다음 환경이 구축되어 있다는 전제로 작성한다.

- Apache(httpd)
- PHP-FPM
- PHP 연동 완료

목표는 PHP의 `Imagick` 확장을 이용하여:

```
HEIC / HEIF 파일 → JPG 변환
```

이 가능하도록 설정하는 것이다.

---

# 1. 전체 구조 이해

HEIC 변환은 아래 구조로 동작한다.

```
PHP 코드
    ↓
Imagick PHP Extension
    ↓
ImageMagick
    ↓
libheif
    ↓
HEIC 파일 디코딩
```

구성요소 역할:

| 구성요소 | 역할 |
| --- | --- |
| Imagick | PHP에서 ImageMagick 사용 |
| ImageMagick | 실제 이미지 처리 |
| libheif | HEIC 포맷 해석 |
| ImageMagick HEIC coder | HEIC 모듈 연결 |

즉:

```
Imagick만 설치되어 있어도 HEIC는 안 될 수 있다.
```

반드시:

- libheif
- ImageMagick HEIC coder

까지 모두 있어야 한다.

---

# 2. 저장소 설정

Remi 저장소 설치.

```
dnf install epel-release-y
dnf install https://rpms.remirepo.net/enterprise/remi-release-8.rpm-y
```

---

# 3. ImageMagick7 설치

HEIC 지원을 위해 ImageMagick7 사용 권장.

```
dnf install-y \
    ImageMagick7 \
    ImageMagick7-devel
```

설치 확인:

```
magick-version
```

정상 예시:

```
Version: ImageMagick 7.x
```

---

# 4. libheif 설치

HEIC 디코딩용 라이브러리 설치.

```
dnf install-y \
    libheif \
    libheif-devel
```

설치 확인:

```
find /usr/lib64-name"*heif*"
```

정상 예시:

```
/usr/lib64/libheif.so
```

---

# 5. ImageMagick HEIC 플러그인 설치

이 단계가 핵심이다.

```
dnf install-y ImageMagick7-heic
```

설치 확인:

```
find /usr/lib64/ImageMagick-7*/modules*/coders-name"*heic*"
```

정상 결과 예시:

```
heic.so
```

이 파일이 실제 HEIC 포맷 처리 모듈이다.

---

# 6. PHP Imagick 빌드 환경 설치

```
dnf install-y \
    php-devel \
    php-pear \
gcc \
make
```

---

# 7. Imagick 설치

## 7-1. 환경 변수 설정

```
exportPKG_CONFIG_PATH=/usr/lib64/pkgconfig
exportMAGICK_HOME=/usr
```

설명:

| 변수 | 역할 |
| --- | --- |
| PKG_CONFIG_PATH | ImageMagick 라이브러리 위치 탐색 |
| MAGICK_HOME | ImageMagick 설치 경로 지정 |

---

## 7-2. Imagick 설치

```
pecl install imagick
```

설치 도중 아래 메시지가 나오면:

```
Please provide the prefix of ImageMagick installation [autodetect] :
```

다음을 입력:

```
/usr
```

---

# 8. PHP에 Imagick 등록

설정 파일 생성:

```
echo"extension=imagick.so" > /etc/php.d/40-imagick.ini
```

---

# 9. Apache + PHP-FPM 재시작

매우 중요.

```
systemctlrestart php-fpm
systemctlrestart httpd
```

Apache는 기존 PHP 프로세스를 유지하기 때문에,

재시작하지 않으면 새 모듈이 반영되지 않는다.

## 10-1. Imagick 로딩 확인

```

```

정상 결과:

```

```

## 10-2. HEIC 지원 확인

```

# 11. 실제 변환 테스트

## PHP 예제

```
<?php

$img=new Imagick('sample.heic');

$img->setImageFormat('jpg');

$img->writeImage('sample.jpg');

echo"complete";
```

---

# 12. 왜 HEIC 변환이 안 되는가?

대표적인 실패 원인:

| 원인 | 설명 |
| --- | --- |
| imagick 미설치 | PHP에서 Imagick 클래스 없음 |
| ImageMagick6 사용 | HEIC 지원 부족 가능 |
| libheif 없음 | HEIC 해석 불가 |
| heic.so coder 없음 | ImageMagick이 HEIC 인식 불가 |
| Apache 재시작 안 함 | PHP 모듈 미반영 |

특히 중요한 부분:

```
Imagick 설치 = HEIC 지원
이 아니다.
```

HEIC 지원 여부는 실제로는:

```
ImageMagick + libheif + heic.so
```

조합이 결정한다.

## imagick.so 연결 확인

```

```
libMagickWand-7

```

```

```

```
HEIC
```

존재해야 한다.
